# 上岸 app

一个基于 uni-app + Vue 3 + Pinia 的个人还款管理应用，用来记录网贷、银行贷款、亲友借款和每月还款进度。数据默认保存在本地存储中，适合个人离线记账和还款计划跟踪。

## 功能概览

- 首页总览：展示待还总本金、本月或下月应还金额、总还款进度、活跃贷款平台数量和亲友借款余额。
- 贷款平台管理：新增、编辑、删除贷款平台，记录借款总额、待还本金、月供本金、月供利息、年化利率、还款日、总期数、剩余期数和还款开始月份。
- 贷款详情：查看单个平台的还款计划、预计结清日期和还款记录。
- 还款记录：支持记录当期还款和提前还款，自动扣减待还本金和剩余期数；删除记录时会恢复对应余额。
- 月度记录：按月份查看应还、已还、待还、本金、利息和各平台还款状态。
- 亲友借款：记录亲友借款人、借款总额、剩余欠款、还款进度和还款事件。
- 音乐播放器：支持网易云音乐、QQ 音乐搜索，播放列表、歌词、播放进度、顺序播放、列表循环、单曲循环和随机播放。

## 技术栈

- uni-app
- Vue 3
- Pinia
- SCSS
- uni 本地存储
- uni InnerAudioContext

```text
    monthly/                 月度还款记录

```

## 运行方式

推荐使用 HBuilderX 打开 `上岸app` 目录运行。

1. 安装 HBuilderX，并准备对应运行目标，例如浏览器、微信开发者工具或 App 真机调试环境。
2. 使用 HBuilderX 打开 `D:\中地\代码\workbuddy\huankuan-app\上岸app`。
3. 运行到目标平台：
   - H5：运行到浏览器
   - 小程序：运行到微信开发者工具
   - App：运行到手机或模拟器

## 数据说明

- 贷款平台数据保存在本地存储 key：`repayment_tasks`
- 贷款还款记录保存在本地存储 key：`repayment_records`
- 亲友借款数据保存在本地存储 key：`repayment_friends`
- 亲友还款事件保存在本地存储 key：`repayment_friend_events`
- 音乐播放设置保存在本地存储 key：`music_settings`

首次进入时，贷款模块会写入少量演示数据；亲友借款模块默认不启用演示数据。

## 注意事项

- 当前项目以本地存储为主，没有接入后端账号体系，多设备之间不会自动同步。
- 音乐播放器依赖第三方 Meting 接口获取歌曲、封面、歌词和播放地址，接口可用性会影响搜索和播放体验。
- `manifest.json` 中配置了 App、H5 和多个小程序平台，可以根据实际发布平台补充 appid、权限和图标资源。
